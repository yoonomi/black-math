# 3–5 分钟演示脚本

1. 打开 http://localhost:7860 ，说明这是同一套影神图图谱上的多模型对照。
2. 问答页选 **智谱**，数据路径保持样例，点「初始化 GraphRAG」。
3. 问「黑风山土地是谁？」：左栏应答游戏里的土地公，右栏纯生成常讲《西游记》。展开下方路径/实体。
4. 换成 **DeepSeek**，再问「哪些头目曾与孙悟空交过手？」：左栏应出现黑风大王、黄风大王。
5. 打开「性能」页，加载 `results.json`：指出 GraphRAG Hit@1（智谱/DeepSeek 均为 1.00）相对纯生成（0.21 / 0.50），以及 DeepSeek 时延更短。
6. 点开题型表，说明事实题、关系题、对比题都来自样例图谱。

需要 Neo4j 已启动。不要展示 `.env` 或 Key。
